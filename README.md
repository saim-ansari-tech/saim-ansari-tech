## 🚀 Featured Projects

### 🧑‍⚕️ AI Dermatology Assistant

An AI-powered healthcare assistant that allows users to interact with an AI skin specialist using **images, video, and voice input**. The system combines multimodal AI with conversational interaction to gather information and provide contextual guidance.

### 🔎 Multimodal Video Understanding & Semantic Search

A multimodal AI pipeline that processes videos using **Whisper-based speech transcription, keyframe extraction, Vision-Language Models, embeddings, and Qdrant vector search**. Users can search video content semantically and retrieve relevant information with timestamps.

### 📄 Semantic Document Search System

A document intelligence system supporting multiple formats including **PDF, DOCX, TXT, and CSV**. Documents are chunked, embedded, stored in a vector database, and retrieved through semantic search with LLM-based question answering.

### 🌊 Autonomous River Cleaner Robot

A robotic boat designed to move autonomously and collect floating waste from the surface of rivers. The project combines **sensors, motor control, embedded systems, and autonomous navigation** for environmental cleanup.

### ✈️ RC Aircraft — DBFC Competition

Designed and developed a fixed-wing RC aircraft for a university-level competition, including aircraft design, simulation, and payload considerations.

### 👋 Hand Gesture Recognition

A computer vision project using deep learning to recognise hand gestures from images. The project explores CNN-based image classification and practical computer vision applications.
